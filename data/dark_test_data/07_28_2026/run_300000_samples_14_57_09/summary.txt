  aligned dphase across channels => one shared source, phase-locked to the carrier.

Verdict
  largest pickup = 892.35 uV.
  Compare pickup uV to the ~80-210 uV noise floor: below it = buried; above = a coherent
  line that WILL bias Var(m)/cov in the cross-sensor cell (subtract it, per analysis.md).

How to read this
  pickup uV    |c_i| = 2*mean(v*e^-jwt): deterministic carrier-band pickup amplitude.
               Random noise averages out; only phase-locked coupling survives.
  phase deg    arg(c_i) vs the demod LO. Compare to the LIT carrier phase (variance cell
               de-rotation ref) to tell an in-phase pickup from a quadrature one.
  in-band uV   incoherent fluctuation in the +/-2 Hz demod band (2*std of baseband).
  % of carrier |c_i| relative to the lit-run a_i -- how much it perturbs that channel.
